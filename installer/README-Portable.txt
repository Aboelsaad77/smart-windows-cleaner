Smart Windows Cleaner — Portable Version
=========================================

No installation. No administrative setup required. No system registry hooks.

RUN
  1. Extract this ZIP to any directory you have write access to (Documents, D:\Tools, USB drive).
  2. Run SmartCleaner.exe.

YOUR DATA & VAULT
  In portable mode, isolated quarantine vaults and SQLite audit ledgers are preserved
  safely. User-level cleanup operates directly without triggering system UAC prompts.

UPDATE
  A portable copy never installs background updates automatically. When notified of
  a new version, download the new Portable ZIP, extract it, and preserve your configuration.

REMOVE
  Delete the folder. Any files actively held in the quarantine vault should be purged
  or restored prior to folder deletion.

Need an installed copy with Start Menu shortcuts and automatic updates?
Use SmartCleaner-Setup.exe (Full Installation) instead.
